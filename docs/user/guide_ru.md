# Rentivo API — Руководство пользователя

## Что такое Rentivo?

Rentivo — это API для личных финансов, который помогает следить за двумя вещами:

- **Банковские вклады** — сколько процентов уже накоплено и когда заканчивается срок.
- **Подписки** — регулярные платежи: стриминг, ПО, спортзал и всё остальное.

Аналитика за год показывает, сколько приносят вклады и сколько уходит на подписки — по месяцам, с прогнозом на будущие месяцы.

---

## Начало работы

### Регистрация

Создайте аккаунт, отправив email и пароль:

```
POST /auth/register
{
  "email": "you@example.com",
  "password": "ваш-пароль"
}
```

В ответ вы получите `access_token` и `refresh_token`. Сохраните оба.

### Вход в аккаунт

```
POST /auth/login
{
  "email": "you@example.com",
  "password": "ваш-пароль"
}
```

### Как использовать токен

Каждый запрос к вкладам, подпискам и аналитике должен содержать заголовок:

```
Authorization: Bearer <access_token>
```

### Обновление токена

Access-токен действует 30 минут. Чтобы получить новую пару токенов без повторного ввода пароля, используйте refresh-токен:

```
POST /auth/refresh
{
  "refresh_token": "<ваш-refresh-токен>"
}
```

## Вклады

### Добавить вклад

```
POST /deposits
{
  "title": "Сбербанк 2026",
  "bank_name": "Сбербанк",
  "amount": "100000.00",
  "currency": "RUB",
  "open_date": "2026-01-01",
  "close_date": "2026-12-31",
  "annual_rate": "17.0"
}
```

- `currency` — одно из значений: `USD`, `EUR`, `RUB`, `GEL`, `BYN`.
- `close_date` — необязательное поле; если не указано, вклад считается бессрочным.
- `annual_rate` — годовая процентная ставка, например `17.0` означает 17%.

### Посмотреть все вклады

```
GET /deposits
```

Каждый вклад в списке содержит два вычисляемых поля:

- `income_to_date` — накопленный доход по формуле простых процентов.
- `days_elapsed` — сколько дней вклад активен (не превышает дату закрытия, если она прошла).

### Посмотреть один вклад

```
GET /deposits/{id}
```

### Изменить вклад

```
PUT /deposits/{id}
{
  "title": "Новое название"
}
```

Можно передать только те поля, которые нужно изменить.

### Удалить вклад

```
DELETE /deposits/{id}
```

## Подписки

### Добавить подписку

```
POST /subscriptions
{
  "title": "Netflix",
  "category": "Развлечения",
  "amount": "15.99",
  "currency": "USD",
  "billing_cycle": "monthly",
  "start_date": "2026-01-01"
}
```

- `billing_cycle` — один из вариантов: `weekly`, `monthly`, `quarterly`, `yearly`, `one_time`.
- `end_date` — необязательное поле, дата окончания подписки.
- `is_active` — по умолчанию `true`.

### Просмотр подписок

```
GET /subscriptions
```

Можно фильтровать список:

```
GET /subscriptions?filter=active      — только активные повторяющиеся подписки
GET /subscriptions?filter=cancelled   — только отменённые
GET /subscriptions?filter=one_time    — только разовые платежи
```

Каждая подписка содержит:

- `next_payment_date` — дата следующего списания (рассчитывается автоматически).
- `monthly_cost` — стоимость подписки, нормализованная к месячному значению.

### Отменить подписку

```
PUT /subscriptions/{id}
{
  "is_active": false
}
```

### Удалить подписку

```
DELETE /subscriptions/{id}
```

## Аналитика

Запрос показывает помесячную разбивку дохода и расходов за год:

```
GET /analytics?year=2026&currency=RUB
```

Ответ содержит строку на каждый из 12 месяцев:

```json
{
  "year": 2026,
  "currency": "RUB",
  "months": [
    {
      "month": 1,
      "year": 2026,
      "deposit_income": "2301.37",
      "subscription_expenses": "1200.00",
      "net": "1101.37",
      "is_projected": false
    },
    ...
  ]
}
```

- Прошедшие месяцы — **фактические** данные (`is_projected: false`).
- Будущие месяцы — **прогноз** (`is_projected: true`) на основе текущих вкладов и активных подписок.
- Учитываются только вклады и подписки в указанной валюте.

## Экспорт данных

Скачайте все ваши вклады и подписки в виде ZIP-архива с двумя CSV-файлами:

```
GET /export/csv
```

Архив содержит `deposits.csv` и `subscriptions.csv`. Их можно открыть в Excel, Google Таблицах или любом другом табличном редакторе.

---

## Импорт данных

Если у вас есть данные из другого источника или из предыдущего экспорта:

```
POST /import/csv
Content-Type: multipart/form-data
file: <zip-архив или csv-файл>
```

- Можно загрузить полный ZIP-архив или один CSV-файл.
- Строки, чей `id` уже есть в вашем аккаунте, **пропускаются** — повторный импорт безопасен.
- В ответе указывается, сколько записей добавлено и сколько пропущено.

## Ошибки

| HTTP-статус | Значение |
|---|---|
| `400 Bad Request` | Тело запроса некорректно или отсутствует обязательное поле |
| `401 Unauthorized` | Токен отсутствует, истёк или недействителен |
| `403 Forbidden` | Заголовок `Authorization` не передан |
| `404 Not Found` | Запись не существует или принадлежит другому пользователю |
| `409 Conflict` | Email уже зарегистрирован |
| `422 Unprocessable Entity` | Ошибка валидации поля (например, отрицательная сумма или неизвестная валюта) |
