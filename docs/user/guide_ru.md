# Rentivo — Руководство пользователя

## Что такое Rentivo?

Rentivo — личный финансовый трекер для отслеживания:

- **Вкладов** — накопленные проценты, срок окончания, простые и сложные ставки.
- **Подписок** — регулярные платежи: стриминг, ПО, спортзал и всё остальное.
- **Недвижимости** — покупка, коммунальные расходы, доход от аренды, прибыль при продаже.

Страница аналитики показывает доходы и расходы по месяцам с прогнозом на будущее, а также отдельную диаграмму расходов по каждому объекту недвижимости.

Веб-интерфейс: **https://annvatlina.github.io/rentivo-ui/**  
API: **https://rentivo-api-production.up.railway.app**

## Начало работы

Откройте приложение и зарегистрируйтесь — введите email и пароль. После входа вы попадёте на главную страницу с карточками-итогами.

## Настройки

Страница **Settings** позволяет:

- Выбрать **валюту по умолчанию** — используется при создании вкладов, подписок и объектов.
- Включить/выключить **модули**: Deposits, Subscriptions, Property.
- Выбрать **тему**: Indigo (фиолетовая), Neutral (серая), Dark (тёмная).
- Загрузить **демо-данные** или удалить все данные аккаунта.

> Модуль Property по умолчанию выключен — включите его в настройках, чтобы вкладка появилась в меню.

## Вклады

### Страница «Deposits»

Таблица всех вкладов с колонками: название, банк, сумма, ставка, дата закрытия, дней активен, накопленный доход.

**Статусы:**
- 🟢 Зелёный — активен
- 🟡 Янтарный — заканчивается через ≤30 дней (плашка с количеством дней)
- Серый — истёк (плашка «Expired»)

Клик по заголовку колонки сортирует таблицу; повторный клик меняет направление. Пагинация — 10 записей на странице.

Кнопка с карандашом открывает форму редактирования.

### Форма вклада

**Простые проценты:**
- Заполните название, банк, сумму, валюту, дату открытия, ставку, дату закрытия.
- Тип процентов: Simple.

**Сложные проценты:**
- Тип процентов: Compound.
- Выберите частоту начисления: daily, monthly, quarterly, annually.

Дата закрытия необязательна — без неё вклад считается бессрочным.

## Подписки

### Страница «Subscriptions»

Фильтр-табы: **All** / **Active** / **One-time** / **Cancelled** — с количеством в каждой группе.

Колонки: название, категория, цикл, сумма, ежемесячный эквивалент, следующий платёж.

**Плашки в колонке «Next payment»:**
- 🟡 Янтарная — платёж сегодня или в ближайшие 7 дней (`today` / `Nd`)
- 🔵 Синяя — платёж в этом календарном месяце (но не в ближайшие 7 дней)

В шапке страницы: если в этом месяце ожидаются платежи, появляется пилюля «N payment(s) this month».

Сумма `/ mo` в шапке учитывает **только ежемесячные подписки** (billing_cycle = monthly) — без пересчёта годовых и квартальных, так как в аналитике они показываются полной суммой в месяц оплаты.

### Форма подписки

- **Billing cycle**: Weekly / Monthly / Quarterly / Yearly / **2 years** / One-time.
- Под полем суммы появляется предпросмотр ежемесячного эквивалента (для нерегулярных циклов).
- `end_date` — необязательно.

## Недвижимость

### Список объектов («Properties»)

Клик по строке → открывает **страницу транзакций** объекта.  
Иконка ⚙️ в последней колонке → **форма редактирования**.

### Страница транзакций (`/properties/:id`)

**Карточки-итоги** вверху:
- **Total invested** — цена покупки + все единоразовые расходы.
- **Expenses** — сумма всех расходов, конвертированная в основную валюту приложения.
- **Income received** — сумма всех доходов, конвертированная в основную валюту.
- **Profit / Status** — прибыль при продаже или статус.

> Конвертация выполняется по актуальным курсам open.er-api.com (кеш 24 ч). Пока курсы загружаются — в заголовке карточки мигает «…».

**Фильтры:**
- Тип: All / Expenses / Income.
- Категория: chips с количеством — только те, у которых есть транзакции.
- Кнопка **Reset** — сбрасывает оба фильтра.

**Таблица:**
- Колонки: тип (иконка), категория, название, сумма, `{основная валюта}` (конвертированная сумма), цикл, дата.
- Все колонки кликабельны для сортировки.
- **Итоговая строка** (`tfoot`) — сумма **всех** отфильтрованных записей (не только текущей страницы):
  - Колонка «Сумма» группирует по реальной валюте транзакций.
  - Колонка «Основная валюта» — конвертированная итоговая сумма.
- Пагинация: 20 записей на странице, по умолчанию новые записи вверху.

**Добавление транзакции** (кнопка «Add»):
- Форма раскрывается над таблицей.
- Выберите тип (Expense/Income), категорию из выпадающего списка, название, сумму, валюту, цикл, дату.
- Категории: Utilities, Maintenance, Mortgage, Tax, Rent, Other.

### Форма редактирования объекта (`/properties/:id/edit`)

Поля: название, адрес, цена покупки, валюта, дата покупки, статус.  
При статусе **Sold** появляются поля: дата продажи, цена продажи, заметки.  
Кнопка Delete (с подтверждением) удаляет объект вместе со всеми транзакциями.

### Импорт транзакций из банковской выписки

Если у вас есть CSV-файл с банковскими транзакциями, его можно подготовить для импорта:
1. Создайте объект в приложении.
2. Скопируйте его UUID из адресной строки (`/properties/{uuid}`).
3. Подготовьте CSV в формате `property_transactions.csv` (см. Export/Import) с нужным `property_id`.
4. Загрузите через Import/Export.

## Аналитика

### Основная диаграмма

Показывает доходы от вкладов (зелёный) и расходы на подписки (красный) по месяцам.

- Стрелки ← год → переключают год.
- Выпадающий список выбирает **валюту отображения** — суммы конвертируются из нативных валют данных через курсы open.er-api.com.
- Прозрачные столбцы — прогноз (будущие месяцы).
- Подписки с годовым/квартальным/двухлетним циклом показываются **полной суммой** в месяц оплаты, а не распределяются по месяцам.

Карточки под диаграммой: Income earned / Subs spent / Net (actual) / Net (full year).

### Диаграмма расходов по объекту

Вторая карточка ниже — расходы и доходы по выбранному объекту недвижимости.

- Выпадающий список объектов в заголовке карточки — переключение мгновенно перезагружает данные.
- Использует тот же год и ту же валюту, что основная диаграмма.
- Если нативная валюта объекта отличается — конвертируется автоматически.
- Под диаграммой: мини-итог Expenses / Income / Net за фактические месяцы.

## Экспорт и импорт

### Экспорт

Кнопка **Export** на странице Import/Export скачивает ZIP-архив с четырьмя CSV:
- `deposits.csv`
- `subscriptions.csv`
- `properties.csv`
- `property_transactions.csv`

Файлы можно открыть в Excel или Google Таблицах.

### Импорт

Перетащите файл или нажмите на зону загрузки. Принимает ZIP (все четыре CSV) или один CSV-файл.

- Записи с уже существующим `id` пропускаются — повторный импорт безопасен.
- Поддерживает импорт из чужого экспорта (генерирует новые UUID).
- Для импорта `property_transactions.csv` — соответствующий объект должен существовать в вашем аккаунте.

Результат: количество созданных и пропущенных записей по каждому типу.

## Коды ошибок API

| HTTP | Значение |
|---|---|
| `401` | Токен отсутствует, истёк или недействителен |
| `403` | Заголовок Authorization не передан, или модуль отключён |
| `404` | Запись не существует или принадлежит другому пользователю |
| `409` | Email уже зарегистрирован |
| `422` | Ошибка валидации поля |
